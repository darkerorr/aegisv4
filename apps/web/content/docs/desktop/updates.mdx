## Updates

Automatic updater artifacts are disabled in the current Tauri configuration. Download a newer verified installer when a release is published; do not assume background updates are active.

## Uninstall

Use **Windows Settings → Apps → Installed apps → Aegis Desktop → Uninstall**. The exact retention of local application data has not been audited, so review the application data folder before manually deleting anything.

## Release history

Only versions present in the generated release manifest are documented. No historical releases are fabricated.
