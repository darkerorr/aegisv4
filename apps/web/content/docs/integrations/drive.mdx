## What Aegis can show

The Drive interface retrieves file metadata and available content through the connected Google account. Content availability depends on file type and granted scopes.

## Boundary

Connecting Google does not silently add Drive contents to every conversation. A specific feature or tool must request the relevant file data.

## Revoke access

Disconnect Google from Connections and review the Google account's connected applications when access should end.
