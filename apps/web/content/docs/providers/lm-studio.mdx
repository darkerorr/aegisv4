## Start the server

Load a model in LM Studio and start its local server. The Aegis default points to `http://127.0.0.1:1234/v1`.

## Discover models

Open Models and refresh the local catalog. If nothing appears, confirm that LM Studio is serving a model and that another process has not occupied port 1234.

## Limits

Capabilities depend on the loaded model. A local endpoint does not automatically provide web search, Gmail or other connected tools.
